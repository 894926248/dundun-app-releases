# DunDun 自有品牌分发

- distribution-id：`dundun`
- Release tag：`dundun-v<version>`
- Windows x64 更新入口：[latest.yml](win32-x64/latest.yml)
- 安装包：[查看发行记录](https://github.com/894926248/dundun-app-releases/releases)

安装支持自动更新的正式版后，软件会自动检查并下载可用更新，用户选择重启安装。关于页也提供手动检查入口。旧客户端首次接入更新器需要安装接入版。

本目录只管理 DunDun 自有包。代理专属包在 distributions/ 下建立平级目录，使用自己的稳定标识、应用身份和更新入口。
